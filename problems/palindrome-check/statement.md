A string is a palindrome if it reads the same forwards and backwards, **ignoring case and any character that is not a letter or digit**.

Print `YES` if the given line is a palindrome, otherwise `NO`.

### Input

A single line of text (up to 1000 characters).

### Output

`YES` or `NO`.

### Example

**Input**
```
racecar
```

**Output**
```
YES
```
